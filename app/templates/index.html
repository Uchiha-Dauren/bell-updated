ДАННЫЕ ШКОЛЫ

Основа хорошего расписания

Готовые классы, учителя и недельная нагрузка по каждому предмету.

После изменения данных школы расписание нужно создать заново. Существующий вариант будет очищен.

Предметы

Учителя

Добавьте предметы, затем выберите их у каждого учителя.

Параллели

Зарегистрируйте уровень обучения, затем добавьте существующие классы по названию.

Количество 0 — добавить классы вручную. Другое число создаст записи с названиями A, B, C… Ученики по классам не распределяются.

Классы и кабинеты

Вторую смену и проверку кабинетов можно включить в настройках.

После регистрации классов задайте недельную нагрузку и назначьте учителей.

Учебный план

Общее количество уроков по предмету для классов одной параллели. Индивидуальную нагрузку можно указать при назначении учителя.

Назначение учителей

Для каждого предмета в классе назначьте учителя. Повторное сохранение обновляет назначение.

Для каждого предмета в классе должен быть назначен учитель.

УЧЕБНАЯ НЕДЕЛЯ

Расписание без пересечений

Класс и учитель не могут находиться на двух уроках одновременно.

Параметры генерации

Быстрый черновик сохраняет первый корректный вариант. Режим «Улучшить распределение» старается сократить окна и выровнять нагрузку, но не гарантирует расписание без окон. Новая генерация может вернуть тот же вариант, если требований много.
